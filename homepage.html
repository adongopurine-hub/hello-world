The web is made of many connected parts.fullstack foundry is aplace to explore how they work together and start creating a complete web applications,from the first screen to the data behind it.

explore the fundamentals

what does " fullstack" mean?

A fullstack web application brings together the parts people see and use with the services and data that makes most experiences work. gitUnderstanding the whole stack helps you build features from end to end

The building blocks

Frontend

The fronted is the part of an application that runs in the browse It presents information, respond to user actions,and makes a product usable.

Backend

The backend handles the work behind the scenes, such as applying application rules, processing requests,and coordinating access to data

Databases

databases store and organize information so an application can retrieve,update, and manage it when needed.

APIs

APIs define how different parts of a system communicate. A browser can use an API to request information or send changes to a back end.

A Practical path to getting started

  1. learn the foundation of the web and how browsers load pages
  2. build clear,accessible interfaces with HTML and CSS
  3. Add behaviour and interface to the application of the data
  4. practise sending requests between fronted and backend
  5. bring the pieces together in a small end to end project

start with the basis,keep experimenting and let each project teach you something new
